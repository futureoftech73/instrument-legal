# Instrument, legal and support pages

Two pages for the Instrument iPhone app, published here because App Store
Connect requires a Privacy Policy URL and a Support URL that anyone can open,
and because an app that reads HealthKit specifically requires a privacy policy.

- [Privacy policy](PRIVACY.md)
- [Support](SUPPORT.md)

The app's own source is private. These two files are copied from it verbatim
and nothing else from it is here.
